The Trivox rules

Trivox uses a fixed symbol for each supported letter. Encoding is reversible: the decoder turns each symbol back into its original letter. Spaces and punctuation stay in place, so your message remains readable after decoding.

01 / One-to-one alphabetEvery English letter has its own symbol. The same letter always gets the same code.
02 / Case-friendlyUppercase and lowercase letters share a code. Decoding returns lowercase letters.
03 / Three-language rootsEnglish letters are supported directly. Bangla and Hindi letters are preserved as readable text for now.
04 / PunctuationNumbers, spaces, emoji and punctuation remain unchanged.

Symbol key

Note: this is a fun secret alphabet, not strong encryption. Anyone with the symbol key can decode it.
